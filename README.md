# Teja Birthday Website 🎉

An interactive, animated birthday celebration web page created for Teja.

## Live Demos
- **Vercel (Production)**: [https://teja-bday.vercel.app](https://teja-bday.vercel.app)
- **GitHub Pages**: [https://nagandlaharshavardhan93.github.io/teja-bday/](https://nagandlaharshavardhan93.github.io/teja-bday/)

## Features
- Interactive flipbook and memories gallery
- Background music and media player
- Confetti and festive animations
- Responsive layout for mobile and desktop
